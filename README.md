# Web Exam 1: Course Portal

- `bootstrap-q1/` : Bootstrap 5 page. Open `index.html` in a browser.
- `course-app/` : React (Vite) app with props, state, conditional rendering, form and React Router.

## Run the React app

```bash
cd course-app
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).
